==============================================================
เกมต่อยอดจาก V23 / V23.1 เดิม ไม่ต้องเริ่มสร้างตัวละครใหม่

สำหรับเจ้าของเกมที่ยังลงเพียง V23 (ยังไม่ได้ลง V23.1):
1. สำรองข้อมูลตัวละครและไฟล์เกมเดิมก่อนอัปเดต
2. เปิด Supabase Dashboard ของ 55-amberlands > SQL Editor
3. ใช้ไฟล์ SQL ภายนอก ZIP ชื่อ 55_AMBERLANDS_V23_2_COMBINED_SQL.sql แล้วกด Run
   ไฟล์เดียวนี้รวม SQL เพิ่มเติม V23.1 และ V23.2 แล้ว อย่ารัน V23.1 ซ้ำโดยไม่จำเป็น
4. ตรวจว่าขึ้น Success และเช็กว่า public.amber_dungeon_attack_v24 พร้อมใช้งาน
5. แตก ZIP NETLIFY_DEPLOY แล้วอัปโหลดโฟลเดอร์ที่มี index.html ไป Deploys ของ
   Netlify เว็บไซต์ 55-amberlands เดิม (ไม่ใช่ Create New Site)
6. ออกจากแอปเกมแล้วเข้าใหม่เพื่อให้ไฟล์ JS ล่าสุดโหลดใหม่
7. ทดสอบโดยใช้ 2 Google Accounts (ผู้เล่น >= Lv.50) ก่อนเปิดให้ทุกคน

อัปเดต V23.2
- ดันเจียนปราสาทมังกรเพลิง และวิหารราชาน้ำแข็ง 3 บอสต่อแห่ง Lv.50+
- รอเพื่อนหน้าแมพจริง พร้อมระบบเชิญ/Ready/เริ่มด้วยหัวหน้าปาร์ตี้
- ดันเจียนมีปุ่ม AUTO, AUTO Skill, เลือกสกิลโจมตี และหุบแถบเมนูมือถือได้
- สัตว์เลี้ยงมี ATK +30%, ฟื้น HP 10% MP 8% ทุก 3 วินาทีขณะบัฟทำงาน
- บอสในดันเจียน: อาวุธ/เสื้อ/ถุงมือ/รองเท้า/แหวน โดยเซิร์ฟเวอร์สุ่มแยกช่อง
- อุปกรณ์บอสแต่ละช่องมีโอกาส 5% ต่อผู้เล่นต่อการเคลียร์ 1 รอบ
- ออปที่ดีที่สุดโอกาส 0.10% ของทุกการเคลียร์ ต่อช่อง (ไม่ใช่ 0.10% ของ 5%)
- หินตีบวกเดิม gw/ga โอกาส 5% ดรอปทีละ 4–5 เม็ดแบบสุ่ม
- แร่อัคคี / แร่เหมันต์ โอกาส 8% ดรอป 1–3 เม็ด และแร่รุ้งดารา 1% ได้ 1 เม็ด
- แร่อัคคีใช้ตีบวกอาวุธ เพิ่มโอกาสสำเร็จ +5%
- แร่เหมันต์ใช้ตีบวกชุด/ถุงมือ/รองเท้า/แหวน เพิ่มโอกาสสำเร็จ +5%
- แร่รุ้งดาราใช้กับทุกประเภท เพิ่มโอกาสสำเร็จ +10% (สูงสุด 95%)
- อุปกรณ์ที่ดรอปจากบอสมีกรอบและพื้นหลังรุ้งในกระเป๋า/หน้าสวม/รายละเอียด
- ของบอสและของกรอบรุ้งถูกกันออกจากระบบขายรวดเร็ว และขายเดี่ยวต้องยืนยัน
- Sprite Sheet 120 สกิลเดิมยังอยู่ใน assets/skills_v23 และเปิดดูได้ใน skill-preview.html

ความปลอดภัย / ข้อจำกัด
- Server-side SQL เป็นผู้สุ่มและแจกของดันเจียน ไม่ใช้ Math.random() จากมือถือ
- อุปกรณ์จะเข้า gear[] และแร่จะเข้า mats{} ของเซฟคลาวด์ตอนกดรับรางวัล
- ถ้าช่อง gear เต็ม 40 ช่อง การรับรางวัลจะไม่สำเร็จ ให้เคลียร์ที่ว่างก่อน
- ยังเป็น Beta: ยังไม่ได้ทดสอบสมบูรณ์กับผู้เล่นหลายเครื่องในเซิร์ฟเวอร์จริง
- ระบบเซฟ/ไอเทมชอปเดิมยังมีข้อมูลเศรษฐกิจบางส่วนที่พึ่งพาฝั่งไคลเอนต์
  ห้ามใช้ระบบนี้เป็นเศรษฐกิจไอเทมรับเงินจริงโดยไม่มี server validation เพิ่มเติม

SQL ไฟล์ต้องรันใน Supabase SQL Editor เท่านั้น ไม่ควรใส่ SQL ใน ZIP Deploy สาธารณะ
