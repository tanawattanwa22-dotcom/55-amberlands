55 AMBERLANDS V23.3 — PATCH ดันเจียน + บอสโจมตีตอบ + อุปกรณ์กลับมาแสดง
=============================================================
ต่อยอดจาก V23.2 เดิมโดยตรง (UI, แผนที่, ตัวละคร, ปาร์ตี้, PET, Item Shop, ดรอป/รางวัลเดิมอยู่ครบ)

สิ่งที่แก้
1. หลังผ่านบอสตัวที่ 3: ซ่อนบอสที่ตาย ไม่แสดงภาพบอสพร้อม 0 HP อีก
2. คูลดาวน์ 4 ชั่วโมงนับจาก finished_at ของเซิร์ฟเวอร์: แสดงนับถอยหลังสด
   เมื่อเวลาครบและรับรางวัลแล้ว สามารถกดเลือกดันเจียนรอบใหม่ได้
3. แสดงปีกคอสตูม อาวุธที่ใส่ (รวมสายหมัด) และสัตว์เลี้ยงในฉากดันเจียนเหมือนฉากหลัก
4. เพิ่มบอสโจมตีกลับทุก ~3 วินาที (เมื่อมีสมาชิกออนไลน์เปิดฉากดันเจียน)
   ดาเมจ/HP บอสและ HP สมาชิกคำนวณและบันทึกที่ Supabase เพียงที่เดียว
5. ยา HP ในดันเจียนใช้จำนวนจากเซฟคลาวด์ ลดจำนวนจากเซิร์ฟเวอร์
   Auto Potion ใช้ค่าร้อยละเดิม / ฟื้นคืนชีพหลังล้ม 12 วินาที ได้ HP 50%
6. แสดงตัวเลขดาเมจที่โจมตีบอสทั้งการตีปกติและสกิล

ติดตั้ง (สำรองข้อมูลตัวละคร/ฐานข้อมูลก่อน)
1. ต้องเคยติดตั้ง V23 SQL และ V23.2 COMBINED SQL สำเร็จมาก่อน
2. Supabase Dashboard ของเกมเดิม > SQL Editor > New query
   วางเนื้อหาจากไฟล์ 55_AMBERLANDS_V23_3_SQL_PATCH.sql (ส่งแยกจาก ZIP) แล้วกด Run
   ต้องเห็น Success ก่อน Deploy เว็บไซต์; สามารถรันแพตช์ซ้ำได้โดยไม่ลบข้อมูล
3. Netlify > เว็บไซต์เดิม 55 AMBERLANDS > Deploys > อัปโหลดไฟล์
   55_AMBERLANDS_V23_3_DUNGEON_BOSS_FIX_NETLIFY.zip
   (ต้องให้ index.html อยู่ระดับบนสุดของเว็บไซต์)
4. รีเฟรชเว็บไซต์แบบล้าง Cache และลงชื่อเข้า Google ใหม่หากจำเป็น
5. ทดสอบ 2 เครื่องพร้อมกัน: รอ Ready เริ่ม > บอสตีคนทั้งคู่ > ใช้ยา > ฆ่า 3 บอส
   > รับหีบ > ตรวจนับถอยหลังจากเซิร์ฟเวอร์ > เข้าใหม่ได้หลังครบ 4 ชั่วโมง

หมายเหตุ
- ไม่ต้องลบเซฟ ไม่ต้องสร้างตัวละครใหม่ ไม่ต้องอัปโหลดไฟล์ SQL ขึ้น Netlify
- คูลดาวน์ที่เริ่มไว้ก่อนหน้าไม่ได้ถูกล้างหรือเร่งเวลาโดยแพตช์นี้
- การโจมตีของบอสถูกขับเคลื่อนด้วยผู้เล่นที่เปิดดันเจียนอยู่ (RPC ทุก ~3 วินาที)
  ไม่ใช่ background cron: หากทุกคนปิดหน้าเกม การโจมตีจะหยุดจนมีคนกลับเข้ามา
- เป็นแพตช์ Beta: ตรวจโค้ดและไฟล์ ZIP แล้ว แต่ยังไม่ได้ทดสอบกับ Supabase
  ของผู้ใช้/Netlify จริง ไม่มีการแก้ฐานข้อมูลอัตโนมัติจากการดาวน์โหลดไฟล์
- โค้ดระบบเศรษฐกิจและการเซฟเดิมยังมีข้อจำกัดด้าน anti-cheat อย่าเปิดขายไอเทมเงินจริง
  จนกว่าจะ audit ระบบ save และการบันทึกไอเทมจากทุกอุปกรณ์อย่างละเอียด
