55 AMBERLANDS V24.2 PIXEL ART — แพ็กสำหรับ Netlify
=================================================
ที่มา: amberlands_v24_pixel.zip ที่ผู้ใช้ส่งมา (V24 Beta ของ Claude)
ระบบพื้นฐาน: V23.4 แยกคูลดาวน์ดันเจี้ยนไฟ/น้ำแข็ง

การติดตั้ง
1) สำรอง ZIP และเก็บ Deploy เดิม V23.4 ใน Netlify ไว้เพื่อ Rollback
2) Deploy ZIP นี้ที่รูทของไซต์ Netlify เดิม โดยไม่สร้างฐานข้อมูล Supabase ใหม่
3) ไม่ต้องรัน SQL; แพ็กนี้ไม่มี SQL เพราะเป็นไฟล์อ้างอิง ไม่จำเป็นต้องเผยแพร่บนเว็บไซต์
4) หากเปลี่ยนชื่อโดเมน Netlify ต้องตั้ง Supabase Auth Redirect URLs / Google OAuth ตามโดเมนใหม่
5) หลัง Deploy ให้รีโหลดหน้าเกมเพื่อรับไฟล์ JS V24.2 ใหม่

งานที่ปรับจาก ZIP Claude
- เก็บ Pixel Art ทั้งหมดและไฟล์เกมเดิม ไม่เปลี่ยนสูตร เลเวล EXP ร้านค้า ระบบออนไลน์หรือ UI
- v24_px_integration.js อ่านอาวุธที่สวมจาก state.eq.W/state.gear จริง รวม metadata บอส
- v24_px_items.js แคชภาพอุปกรณ์แยกตาม LV ความหายาก และการตีบวก
- เพิ่ม v24_px_equipment_fx.js ใช้ state.eq/state.gear แสดงแสงอาวุธ เสื้อ ถุงมือ รองเท้า แหวน
  ของบอสบนตัวละครในหน้าต่อสู้ และเปลี่ยนทั้งพื้นหลัง + กรอบการ์ดบอสให้เป็นสีรุ้ง
- นำปุ่ม Pixel Codex ที่ Claude เพิ่มเข้ามาบน UI เกมออกตามคำสั่ง ห้ามเปลี่ยน UI
  แต่ยังเข้าหน้าแยกที่ /pixel-codex.html ได้
- ปรับเวอร์ชัน query string ของ JS และใส่ _headers เพื่อลดปัญหาไฟล์แคชเก่า

ไฟล์ระบบเดิมที่ตรวจไบต์ตรงกับ V23.4
online_bridge.js, v23_dungeon.js, v12_patch.js, v14_skill_fx.js,
v15_potion_hit_fix.js, v16_inventory_market.js, v19_skills_market_realtime.js,
v23_bulksell.js, v23_skill_realtime.js, v23_1_mobile_menu.js

ทดสอบแล้ว (ทดสอบออฟไลน์โดยไม่ติดต่อ Supabase)
- ตรวจ Node.js ไวยากรณ์ JavaScript ทุกไฟล์ ผ่าน
- ตรวจลิงก์ <script src> ที่อ้างใน HTML ไม่มีไฟล์ขาด
- พบ 48 มอนสเตอร์ในระบบเดิมและพบรายการวาด Pixel Art ตรงกันครบ
- Chrome ออฟไลน์โหลดงานภาพ V24 ได้ ไม่พบ JavaScript page error ระหว่างทดสอบเปิดหน้า
- จำลองการสวมใส่อุปกรณ์บอสห้าชิ้นในเบราว์เซอร์ทดสอบ ได้เอฟเฟกต์ห้าตำแหน่ง
- หลัง render() เกมเดิมสร้าง UI ใหม่ เอฟเฟกต์ถูกนำกลับมาได้

ยังไม่ได้ยืนยัน
- การเข้าสู่ระบบ Google บน Netlify จริง, ตัวละครจาก Cloud, Realtime 20-100 คน,
  การซื้อ Item Shop ด้วยเงินจริง/เครดิต, RPC ต่อสู้กับบอส, การแจก Loot จริง,
  คูลดาวน์แยกดันเจี้ยน, การบันทึกตัวละครจริง และประสิทธิภาพบนโทรศัพท์ของผู้ใช้
- V24 ของ Claude ใช้ภาพพิกเซลวาดด้วยโค้ด; อย่าเข้าใจว่ามีภาพเดิน 8 ทิศ
  หรือตารางสกิล 60 เฟรมต่อสกิลครบแล้ว เนื่องจากไม่มีหลักฐานการทำครบดังกล่าว

คำแนะนำ: หลัง Deploy ให้ใช้บัญชีทดสอบตรวจ Google login, save/load, ซื้อปีก/สัตว์เลี้ยง,
สวมอุปกรณ์บอสห้าชิ้น, สกิล 120, ฟาร์ม, ตลาดออนไลน์ และดันเจี้ยนทั้งสองแห่ง
ก่อนให้ผู้เล่นจริงใช้งาน ถ้าพบข้อผิดพลาดให้ Rollback กลับ Deploy V23.4 เดิม

ไม่เปลี่ยน Supabase, SQL, RPC, ความน่าจะเป็นดรอป, ดาเมจ หรือข้อมูลผู้เล่นในขั้นตอนนี้
