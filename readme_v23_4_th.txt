55 AMBERLANDS V23.4 — คูลดาวน์ดันเจียนแยกกัน (V23.3 base)
=======================================================
- มังกรเพลิง 4 ชม. และวิหารน้ำแข็ง 4 ชม. แยกจากกัน
- หลังเคลียร์ครบ 3 บอส กดเปิดหีบ และกดรับรางวัลก่อน
  จากนั้นกด “รับรางวัลแล้ว เลือกดันเจียนถัดไป” ได้ทันที
- ตอนเลือกดันเจียน ระบบแสดงเวลารอเป็นรายดันเจียน
- ฝั่ง Supabase ตรวจเงื่อนไขแยกแบบเดียวกันทั้งสร้างห้อง/เชิญ/ตอบรับ/เริ่มสู้
- คูลดาวน์จาก V23.3 ที่ยังเหลือจะถูกย้ายไปผูกกับดันเจียนที่เคลียร์ล่าสุด
  จากประวัติห้องเซิร์ฟเวอร์ ไม่รีเซ็ตและไม่ลบข้อมูล
- V23.3: ระบบบอสโจมตีกลับ HP ยา ฟื้นคืนชีพ ปีก/หมัด และ AUTO เหมือนเดิม
- V23.2: ระบบดรอปอาวุธรุ้ง ชุดรุ้ง แร่รุ้ง โอกาสดรอป ออปเทพ และหีบเหมือนเดิม

ติดตั้งตามลำดับ:
1. สำรองฐานข้อมูล Supabase / ข้อมูลเกมก่อน
2. ระบบเดิมต้องติดตั้ง SQL V23, V23.2 COMBINED และ V23.3 PATCH มาก่อนแล้ว
3. Supabase > SQL Editor > New query: วางเนื้อหาจาก
   55_AMBERLANDS_V23_4_SEPARATE_COOLDOWNS_SQL_PATCH.sql แล้ว Run ให้ Success
4. Netlify > Deploys: อัปโหลด ZIP V23.4 เข้าเว็บไซต์เดิม
5. รีเฟรชเว็บไซต์ / บังคับอัปเดตแคช แล้วทดลองบัญชีที่เคลียร์มังกรและยังติดคูลดาวน์:
   สลับไปน้ำแข็งได้ทันที แต่เข้ามังกรซ้ำไม่ได้จนกว่าจะครบ 4 ชั่วโมง

หมายเหตุสำคัญ:
- ไม่ต้องลบ SQL เก่า ไม่ต้องลบตาราง ไม่ต้องล้างตัวละคร
- SQL V23.4 เป็นแพตช์ ไม่ใช่ SQL ติดตั้งเกมจากศูนย์
- SQL V23.4 อัปเดตฟังก์ชัน create/invite/answer/start/snapshot/attack เท่านั้น
  ไม่สร้างรางวัล ไม่สุ่มอุปกรณ์ใหม่ และไม่ล้าง gear หรือ mats
- หลีกเลี่ยงรัน SQL V23/V23.2/V23.3 ทับหลัง V23.4 เพราะจะคืนฟังก์ชันคูลดาวน์แบบเก่า
- ยังไม่ทดสอบกับเซิร์ฟเวอร์ Supabase จริงของคุณ กรุณาทดสอบก่อนให้ผู้เล่นเข้าเยอะ
